# Word Detective — Probability for AI

Проект по курсу **Probability for Artificial Intelligence** (Stanford PAI).

## О проекте

**Word Detective** — интерактивный анализ частоты слов в текстах, написанных AI и человеком. Для каждого слова вычисляется:

- `P(W|A)` — вероятность встретить слово в AI-тексте;
- `P(W|H)` — вероятность встретить слово в человеческом тексте;
- `Ratio` — отношение этих вероятностей, показывающее, насколько слово характерно для AI или человека.

Формула оценки (сглаживание Лапласа):

    P(W|A) ≈ (count(W|A) + 1) / (n + 2)
    P(W|H) ≈ (count(W|H) + 1) / (n + 2)

## Результат для слова "amazing"

- **P(amazing | A) ≈ 0.01** — слово встречается примерно в 1% AI-текстов.
- **P(amazing | H) ≈ 0.00** — в человеческих текстах практически отсутствует.
- **Ratio ≈ 10** — у AI встречается в 10 раз чаще, чем у человека.

**Вывод:** `amazing` — редкое, но характерное для AI слово.
